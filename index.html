이용 및 배포 안내 가이드

📊 1. 참석 여부 엑셀(Google Sheets) 자동 정리 방법

하객들의 참석 여부를 구글 엑셀 시트로 자동 정리를 원하시는 경우:

  1. Google Forms (구글 설문지)에서 '신랑/신부측', '성함', '참석여부' 3개 질문으로 설문지를 만듭니다.
  2. 설문지 응답 탭에서 '스프레드시트에 연결'을 누르면 엑셀 파일 형태로 실시간 자동 정리됩니다.
  3. 생성한 Google Form 설문지의 URL을 복사하여 본 HTML 코드 내 submitRSVP() 함수에 window.open('구글설문지주소')로 연결하시면 더 쉽게 관리할 수 있습니다!

🌐 2. GitHub Pages 무료 배포

  1. GitHub 회원가입: github.com 접속 후 가입.
  2. 저장소 만들기: New repository → 이름에 wedding 입력 → Create repository 클릭.
  3. 파일 추가: creating a new file 클릭 → 파일명을 index.html로 지정 후 이 전체 코드를 복사해서 붙여넣기 → Commit changes 클릭.
  4. 웹사이트 발행: 저장소 상단 Settings → Pages 메뉴에서 Branch를 main으로 선택 후 Save. 약 1분 후 나만의 모바일 청첩장 링크가 완성됩니다!
